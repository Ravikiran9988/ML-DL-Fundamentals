# ML + Deep Learning Fundamentals — Full Beginner → GenAI Edition

A beginner-friendly, structured path from machine learning and deep learning fundamentals to modern GenAI concepts.

## What's Included

- **10-Day Learning Path** — NumPy, Pandas, regression, regularization, evaluation, neural networks, PyTorch, MNIST, self-attention, and Transformers.
- **GenAI Bridge** — LLMs, embeddings, vector databases, RAG, tools, agents, MCP, evaluation, and security.
- **Assignment Guide** — Hints, solutions, acceptance criteria, and practical tasks for Days 1–10.
- **Project Ladder** — Progressive projects connecting ML/DL fundamentals to GenAI applications.
- **Study Toolkit** — Cheat sheets, checkpoints, revision guidance, glossary, and references.
